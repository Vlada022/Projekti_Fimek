1. Overview & Tool Summary

The Code Quality Analyzer is an embedded static analysis suite. It analyzes source code for vulnerabilities, bad practices, cognitive complexity, and duplicate logic without requiring external compiler binaries.

Analysis Tool Primary Focus Areas What It Detects in Our App
SonarQube Security Vulnerabilities, Reliability (Bugs), Code Smells, Technical Debt SQL Injection risks, direct string concatenation in queries, unhandled exception blocks, hardcoded credentials.
PMD Design Architecture, Cognitive Complexity, Duplication (CPD) Deeply nested loops ($O(N^2)$ quadratic complexity), duplicate validation code blocks across multiple branches.
ESLint Syntax Integrity, Variable Scope, React Best Practices, Style Rules Missing React key props in mapped components, residual console.log calls, obsolete var keywords, inline function bindings inside loops.

3. Practical Preset Examples: UI, Code & Output Breakdown

Preset 1: Movie Search SQL Injection & Sync Block
SonarQube + ESLint + PMD

Code File Analyzed: movie-db-adapter.ts (Language: TypeScript)

Code Snippet Evaluated:

export function searchAndFilterMovies(dbConnection: any, titleQuery: string, genreFilter: string) { // CRITICAL: SQL Injection Risk - Direct query concatenation const query = "SELECT * FROM movies WHERE title LIKE '%" + titleQuery + "%' AND genre = '" + genreFilter + "'"; console.log("Searching database with raw query: " + query); const statement = dbConnection.prepare(query); const results = statement.all(); // ESLint Warning: unused variables left in local scope const cachedAt = new Date().toISOString(); ... }

How It Is Implemented in Backend Code (`server.ts`):

  • SonarQube Regex Rule (SQL Injection Risk): Scans for SELECT ... + input patterns, creating a high severity Security Flaw violation under Rule ID S2068/S1523.
  • ESLint Rule (`no-console`): Flags console.log("Searching...") statement on line 49.
  • ESLint Rule (`no-unused-vars`): Flags unused local variable cachedAt.

What It Provides You in the UI:

  • Quality Gate Status: FAILED (Security Rating downgraded to D).
  • Overall Quality Score: 65 / 100 due to critical SQL injection risk.
  • Technical Debt: 1h 30m remediation estimate.
  • Refactored Code Output: Replaces raw string concatenation with secure SQL parameter placeholders:
    const query = "SELECT * FROM movies WHERE title LIKE ? AND genre = ?"; const statement = dbConnection.prepare(query); const results = statement.all(`%${titleQuery}%`, genreFilter);
Preset 2: Movie Grid Complex Render & Keys Warning
ESLint Featured Target

Code File Analyzed: MovieGridRenderer.jsx (Language: JavaScript / React JSX)

Is ESLint Used Here?

YES! ESLint is the primary target engine for this preset example. It checks React JSX best practices, missing keys, and prohibited inline handler bindings.

Code Snippet Evaluated:

export default function MovieGridRenderer({ moviesList, filterText, selectedGenre, onSelect }) { // Cognitive complexity design smell: deep nesting if (moviesList !== null && moviesList !== undefined) { if (moviesList.length > 0) { for (let i = 0; i < moviesList.length; i++) { if (moviesList[i].rating >= 0) { if (moviesList[i].title.toLowerCase().includes(filterText.toLowerCase())) { if (selectedGenre === 'All' || moviesList[i].genre === selectedGenre) { displayedMovies.push(moviesList[i]); } } } } } } return ( <div className="grid grid-cols-3 gap-4"> {displayedMovies.map((movie) => ( // WARNING: Missing "key" prop on mapped element! <div className="movie-card"> <button onClick={() => { console.log(movie.title); document.title = movie.title; }}> View Details </button> </div> ))} </div> ); }

How It Is Implemented in Backend Code (`server.ts`):

  • ESLint Rule (`react/jsx-key`): Detects displayedMovies.map(...) rendering JSX elements without a unique key={movie.id} prop.
  • ESLint Rule (`no-console`): Identifies inline console.log(...) statement inside the button onClick handler.
  • ESLint Rule (`react/jsx-no-bind`): Detects inline arrow function allocation inside the render loop (creates new memory references on every re-render).
  • PMD Rule (`AvoidDeeplyNestedLoops`): Identifies 5 levels of nested if statements and loops, flagging elevated Cognitive Complexity.

What It Provides You in the UI:

  • ESLint Warning Count: 3 Warnings (Missing React key, console log, inline function bind).
  • PMD Complexity Rating: High Cognitive Complexity (Quadratic branching depth).
  • Refactored Code Output: Converts deep nested if statements into clean array .filter() guard clauses and adds key={movie.id} to mapped React cards.
