Besplatni Alati za Prikaz i Editovanje Dijagrama (Free UML Tools)

1. Mermaid Live Editor

Besplatan web editor bez registracije na mermaid.live. Podržava instant render, SVG/PNG export i deljenje dijagrama.

2. PlantUML Web Server

Otvorite kod na plantuml.com/plantuml ili koristite VS Code ekstenziju PlantUML za lokalno generisanje.

3. Diagrams.net (Draw.io)

Besplatan alat na app.diagrams.net (opcija Arrange > Insert > Advanced > Mermaid / PlantUML za instant uvoz).

1.2 PlantUML Kod (za plantuml.com ili Draw.io) PlantUML Source 
@startuml
skinparam classAttributeIconSize 0
skinparam class {
  BackgroundColor White
  BorderColor #4338ca
  ArrowColor #4338ca
}

class User <<Entity>> {
  +String id
  +String username
  +String password_hash
  +String role
  +String bio
  +String created_at
}

class Movie <<Entity>> {
  +String id
  +String user_id
  +String title
  +Integer year
  +String genre
  +Double rating
}

class ActivityLog <<Entity>> {
  +Integer id
  +String user_id
  +String action
  +String details
  +String timestamp
}

class DatabaseService <<Service>> {
  +hashPassword(password): String
  +createUser(user): User
  +authenticateUser(user, pass): User
  +getAllMovies(query): Movie[]
  +createMovie(userId, data): Movie
  +deleteMovie(id): Boolean
  +logActivity(userId, action): Void
}

class ExpressAPIControllers <<Controller>> {
  +POST /api/auth/login()
  +GET /api/movies()
  +POST /api/movies()
  +DELETE /api/movies/:id()
}

class ReactUI <<Boundary>> {
  +LoginForm (#btn-prefill-admin)
  +MovieGrid (#movie-search)
  +AddMovieModal (#movie-title)
}

User "1" o-- "0..*" Movie : creates
User "1" o-- "0..*" ActivityLog : logs
DatabaseService ..> User : manages
DatabaseService ..> Movie : manages
ExpressAPIControllers --> DatabaseService : invokes
ReactUI --> ExpressAPIControllers : REST HTTP
@enduml

2.2 UML Dijagram Sekvenci: E2E Test Izvršenje (Sequence Diagram) UML Sequence 
@startuml
autonumber
actor "CI Runner / QA" as QA
participant "Playwright Engine" as Engine
participant "Browser (Chromium)" as Browser
participant "React Frontend" as UI
participant "Express Backend" as Server
database "SQLite DB" as DB

QA -> Engine : npm run test:e2e
Engine -> Browser : launch(headless=true)
Browser -> UI : goto("http://localhost:3000")
UI -> Browser : Render Login Form (#btn-prefill-admin)

Browser -> UI : Click #btn-prefill-admin & #btn-submit-auth
UI -> Server : POST /api/auth/login
Server -> DB : SELECT * FROM users WHERE username='admin'
DB --> Server : User Record & SHA-256 Hash
Server --> UI : HTTP 200 { success: true, user: admin }
UI --> Browser : Render Movie Catalog Dashboard

Browser -> UI : Click #btn-add-movie-trigger & Fill Form
UI -> Server : POST /api/movies
Server -> DB : INSERT INTO movies VALUES (...)
DB --> Server : Success
Server --> UI : HTTP 201 Movie Created
UI --> Browser : Show Movie Card in DOM

Browser -> Browser : Register page.once('dialog', accept)
Browser -> UI : Click .test-btn-delete-movie
UI -> Browser : Show Confirm Dialog ("Are you sure?")
Browser --> UI : Accept Dialog
UI -> Server : DELETE /api/movies/:id
Server -> DB : DELETE FROM movies WHERE id=:id
DB --> Server : Success
Server --> UI : HTTP 200 { success: true }
UI --> Browser : Remove Movie Card from DOM
Engine --> QA : 8 Passed (100% Success)
@enduml
